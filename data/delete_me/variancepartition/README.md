## Variance Partition files

  Data was obtained from different objects in `data(varPartDEdata)` from `library("variancePartition")`.

- **countmatrix.csv**  
  Data was obtained from the 1000 first elements in the `countMatrix` object. The `gene_id` column was created from rownames. 

- **metadata.csv**  
  Data was obtained from the `metadata` object.  The `sample` column was created from rownames.
